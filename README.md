# Program Rimba PWA

Versi web/PWA mobile-first untuk tracking body recomposition pribadi.

Fitur: Dashboard, Full Body A/B, set-load-reps, aktivitas, pengukuran BB/lingkar perut, grafik, edit/hapus, backup/restore JSON, localStorage, dan offline cache.

Untuk instalasi PWA di Android, app harus disajikan melalui HTTPS (atau localhost untuk pengembangan). Setelah dibuka di Chrome, gunakan opsi Install/Add to Home Screen bila tersedia.
